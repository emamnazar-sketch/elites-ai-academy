# Elites AI Academy — Student Portal (demo)

A simple, static student portal for Elites AI Academy, modeled on a classic
training-portal layout: login page, "My Training" dashboard with course cards,
progress tabs, and a slide-in menu.

Front-end demo only — no real accounts, no backend, no payments.
Demo login: any email + any password of 4 or more characters.

Course: "Everyday AI Literacy: From First Chat to AI Agents"
5 levels · 12 modules · 72 lessons (each module about 1 hour).

Deployed on Cloudflare Pages. Custom domain to be connected later.
